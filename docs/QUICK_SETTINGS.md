下拉快捷面板

从屏幕顶部向下拖动展开面板；从面板底部向上滑动，或轻点面板外的背景收起。
轻点应用顶部的按钮仍按原来的行为响应，左右滑动桌面也会保留。

- WiFi、蓝牙、热点：轻点切换开关，长按进入对应设置页。切换过程显示
  “切换中”，失败时显示“操作失败”，按钮状态以驱动实际结果为准。
  1.9.0 起，热点使用中心圆点和双侧波纹图标，与 WiFi 图标区分，设置列表同步更新。
  1.9.2 将波纹简化为左右各两道，并放大图标、加粗线条，快捷栏和设置列表同步调整。
  1.9.3 将短线段拼接改为连续抗锯齿圆弧，保留圆润端点，改善边缘圆滑程度。
  2026-11-14 用户已在 1.9.3 实机确认热点图标弧形圆滑。
- 亮度：滑动即时调节，范围为 5%–100%。
- 音量：滑动即时调节，范围为 0%–100%；松手时保存，设置页与面板同步。
- 右上角齿轮进入设置应用；设置应用也新增蓝牙和热点入口。

设置应用首页采用统一的横向卡片列表：WiFi、亮度、息屏时间、音量、蓝牙、热点、
设备信息、系统更新、重启设备和重启屏幕。卡片为 420×64，左侧小图标、文字和右侧
箭头对齐，行间距 12 像素；顶部标题固定，仅下方内容纵向滚动。
当前开发版已将顶部返回键替换为[侧边内滑返回](DESKTOP_UI.md)。
点击 WiFi、亮度和音量仍进入各自的设置页，滑动调节与配置保存方式不变。

在“设置 → 息屏时间”中选择 1、2、3、5、10、20、30、60 分钟或“永不”。
默认 5 分钟，选择后保存，重启后仍保留。屏幕亮着时，触摸和持续按住均会
重新计算空闲时间；音乐播放、网络请求和设备移动不会延长此计时。
自动息屏后，双击屏幕或转动设备可亮屏，恢复息屏前设置的亮度。
单击、长按和拖动不会触发双击唤醒，唤醒触摸不会点击底下的应用。
息屏期间仅关闭背光，音乐、热点、文件上传和系统更新继续运行。

2026-11-14 已完成真实 LVGL/中文字库渲染、IDF 构建及 COM79 烧录，
烧录前后 NVS 和 OTA 元数据读回一致。用户已确认新版布局正常、入口均能打开。

共享 WiFi 上网时，先在设备 WiFi 设置中连接可上网的 2.4 GHz 网络，再开启
热点。长按热点查看名称、密码、地址和连接设备数，用手机等终端连接。
1.13.0 可在“热点设置 → 修改名称和密码”中编辑并保存名称，支持中文，最多
32 字节，重启后保留；未自定义时由设备 MAC 后缀生成。改名后手机需重新连接。
详见[热点名称说明](HOTSPOT_NAME.md)。WPA2 密码独立随机生成并保存在 NVS，
不使用上游 WiFi 的密码。上游断开时，热点设置页会提示连接 WiFi。
测试时需要独立上游：路由器或手机 A 给 ESP32 提供互联网，手机 B 连接
ESP32 热点。若手机 A 是上游，应保持其移动数据开启；只关闭测试手机 B
的移动数据。同一部手机既提供上游热点又连接 ESP32 热点会形成循环。
热点的 IPv4 上网共享使用 AP+STA、ESP-NETIF NAPT 和 DHCP DNS 配置。
热点会选择与已知上游不重叠的独立网段，默认从 `172.31.42.1/24` 开始选择；
具体地址以设置页显示为准。上游重连后会重新确认 NAPT 和 DHCP DNS 配置。

蓝牙使用 ESP32-S3 的 BLE 外设模式，开启后广播设备名称，支持 Just Works
配对、加密和 NVS 绑定保存；BLE 数据会话仍需相应 GATT 客户端应用，
不提供经典蓝牙音频或经典 SPP。重启后 WiFi 默认开启，蓝牙和热点
默认关闭，已有 WiFi 凭据、壁纸和音量配置继续保留。

界面实现位于 `src/QuickPanel.c`，异步开关请求由
`src/QuickSettingsService.cpp` 在 AppServices 任务中处理；WiFi/热点在
`src/setwifi.cpp`，BLE 在 `src/QuickBluetooth.cpp`。所有 LVGL 操作仍在
GUI 任务中执行，无线回调不直接操作 LVGL。

为保留三种无线功能同时开启时的内部内存，BLE host 分配使用 PSRAM，
LVGL 内存池为 2.5 MiB。BLE 控制器代码使用缓存区，编译时要求同时保留
PSRAM 指令和只读数据 XiP；控制器数据、DMA 和任务栈仍使用内部 RAM。
热点启动后等待 ESP-NETIF 接口就绪再启用 NAPT，失败时清理资源。
