# 自定义热点名称和密码（1.13.1）

进入“设置 → 热点 → 修改名称和密码”，修改后点击“保存”。名称和密码一同保存，
成功后显示“已保存”；取消不修改配置。修改正在使用的热点后，手机需重新连接；
如果保留了相同名称，手机可能需要先忘记旧网络，再输入新密码。

- 名称支持中文、英文、数字及可显示的 UTF-8 字符，最多32字节，汉字一般占3字节。
  名称两端的普通空格会去掉，空名称、过长名称、控制字符或无效 UTF-8 不允许保存。
- 密码为8-63位英文、数字或符号（可显示ASCII字符）。密码不裁剪两端空格。
  默认隐藏，点击“显示”可以核对，再点击“隐藏”恢复遮盖；重新进入页面时恢复隐藏。
  密码输入使用普通键盘，名称输入保留中文拼音候选，切换输入框不会把密码转成中文。

名称和密码保存在 NVS `hotspot_cfg/credentials` 的一个带版本条目中，重启后继续使用。
旧版的 `hotspot_cfg/ssid` 名称和 `hotspot/psk` 随机密码会继续读取，更新固件不会
主动重置它们。未配置时保留 MAC 名称与设备生成的随机密码。已关闭的热点不会因为
保存配置而打开；重启后要用手机核对名称和密码，需要再次开启热点。

保存通过 AppServices 异步执行；保存期间输入暂时禁用，完成后恢复。失败显示错误并
尝试恢复原设置；未显示“已保存”时应根据提示重试。修改时保留原有认证方式、信道、
上游 WiFi 和共享网络配置。

相关实现：`HotspotName.cpp/.h` 管理校验、NVS、任务和失败恢复；`setwifi.cpp` 的
`wifi_hotspot_apply_credentials` 更新运行时配置；`HotspotNameUI.c/.h` 提供双输入框、
密码显示/隐藏、键盘和保存；`QuickPanel.c` 提供入口。

验证：`tests/hotspot_name_host_test.py` 使用真实后端与 AP 更新、密码恢复函数，
覆盖 UTF-8、32字节名称、8/63/64位密码、旧配置、整组保存、重启读取、AP开关状态、
驱动/NVS错误、失败恢复以及认证方式/信道/NAPT保留；
`tests/hotspot_name_ui_host_test.py` 使用真实 LVGL 和字库检查双输入框、中文拼音、
63位密码原文输入、显示/隐藏、保存/取消/错误、键盘返回和重复删除。
