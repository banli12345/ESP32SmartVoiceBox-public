# 当前版本：Breeze OS 1.28.0

当前为原生ESP-IDF 5.5.6、ESP32-S3 N16R8和LVGL8源码，保留最新一个无父提交快照。提供占位符API配置、图解使用、硬件连接表、原理图和实机演示。提供[当前通用固件包](../firmware/README.md)；运行字体与个人媒体需另行准备。

| 功能 | 当前行为 |
| --- | --- |
| 服务配置 | 手机热点网页 `/settings`，自己的 AI/天气/生活指数地址与 Key 分别保存到 NVS，显式重启启用；已有 Key 不回显、留空保留，SD 导入兼容。 |
| 通用构建 | 默认不编入个人 WiFi/API 凭据，现有设备 OTA 保留 NVS；公开示例只含占位符。 |
| 天气 | 原天气API、中文市县输入、官方3239条位置记录、40枚内置天气代码图标、大温度与三日预报。Key权限仍由服务端决定。 |
| 中文键盘 | 四排QWERTY、宽Space、CN/EN、数字/符号页，候选可翻页/展开。 |
| 音乐 | 设备本机页和手机网页均先临时缓存播放；点击当前歌曲旁“下载”才转存SD歌单WAV与可用LRC。 |
| 相册 | 校验后优先整图加载，内存不足按行读取；切图与关闭释放，避免旧任务发布过期图片。 |
| 亮屏 | ROLL/PITCH双轴0.525rad/s持续60ms，忽略Z；触摸息屏计时与双击唤醒。 |
| AI/语音 | DeepSeek直连，完整语音缓存SD后播放并清理；男女声、停止、缓存均速；城市别名压缩释放384KiB常驻预算。 |
| 桌面/设置 | 青禾约3秒开机、翻页数字时钟、农历和生活指数、侧边返回、图标拖动排序、滑动亮度/音量。 |
| 网络/闹钟 | 保存8个WiFi、热点改名改密及共享上游网络；单闹钟支持重复日期、响铃时长及倒计时。 |
| 游戏/背词 | 六款离线游戏，含五子棋和100张随机散牌三消；四级词条中英文配对，独立SD词库。 |
| 媒体/OTA | 手机网页转换照片/视频并上传，长按改名、竖点确认删除；SD候选应用OTA。 |

用户已确认：网页分别保存 AI/天气、空 Key 保留，重启后天气/生活指数/AI 正常；缓存后短句/故事播报正常，照片恢复且反复打开正常，双轴判断及双击唤醒正常。中文城市设备输入、全部天气状态、显式下载与全部新键盘组合尚无完整实机确认；相应主机检查不能替代设备操作。
