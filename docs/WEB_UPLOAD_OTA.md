# 热点文件上传与系统更新

当前版本 1.8.0。网页仍在设备热点原地址，音乐点播功能保留。

## 照片与视频

- 照片：选择 JPEG、PNG、WebP，浏览器按比例适配 480×480，转换为 RGB565 LVGL `.bin` 后分块上传 `/imges/`。也可直接上传已有相册 `.bin`（支持 RGB565 和 RGB565+Alpha）。相册同时扫描 `/imges/` 与 `/images/`，原有照片保留。
- 视频：手机浏览器可解码的 MP4/WebM，可转换为 320×240、10 FPS 的 RVF；源文件最多 50 MiB，时长最多 60 秒。浏览器逐帧转换、逐块上传，不在 ESP32 内解码 MP4。请保持网页在前台。
- 勾选“包含声音”时，浏览器解码音轨并转为同名 44.1 kHz、双声道、PCM16 WAV，先保存音轨再上传视频。无法解码声音时明确报错，可取消勾选后上传无声视频。
- 原生 RVF 可直接上传（最多 256 MiB），同名配套 WAV 可在独立入口上传（最多 64 MiB）。电脑转换继续使用 `scripts/convert_video.py`。RVF 与 WAV 保存到 `/videos/`。
- 媒体同名时拒绝覆盖，可修改网页保存名称。上传后重新进入相册或视频应用，列表重新扫描。照片和视频数量仍受原播放器列表容量限制。
- 单次只进行一项传输，上传块不超过 64 KiB。取消、断连或闲置超时会清理未完成的暂存文件，已有完整文件保留。如果视频在配套 WAV 已完成后取消，网页会列出已保存音轨路径。

浏览器实际可解码的编码取决于手机。无法转换的文件可先在电脑转换为原生 RVF/WAV，不使用外部转码服务器。

## 固件更新

1. 连接设备热点并打开网页，选择“固件与系统更新”。
2. 上传本工程 `build/esp32_smart_voice_box.bin` 应用文件（最大 4 MiB）。不能上传 bootloader、partition-table、照片 BIN 或合并 Flash 镜像。
3. 文件经 ESP32-S3 芯片、工程名、段长度、校验和及 SHA-256 校验后，保存为 `/updates/firmware.bin`；上传不会立即安装。
4. 在设备打开“设置 → 系统更新 → 检查更新”。若检测到更新，可点击“安装并重启”并确认。
5. 设备从 SD 卡读取并写入未运行的 OTA 分区。写完且 SDK 校验通过才切换启动；失败时继续使用当前固件。保持供电并保留 SD 卡。
6. 新固件启动后，界面和音频任务正常运行满约 20 秒会确认启动成功。在新系统确认前若发生复位，支持回滚的引导程序会选择之前有效的系统。

每次正式发布请递增根 CMakeLists.txt 的项目版本。相同 ELF 不会重复提示更新；较低版本不升级；同版本仅在编译时间更新且 ELF 不同时提示更新。安装前再次校验文件，并核对“检查更新”时记录的固件，避免检查后文件被替换。

固件首次上线时需要随本版更新启用回滚的 bootloader；分区表与 NVS 无需重建。此后的正常升级通过网页和设置即可完成。更新保留 SD 卡媒体、WiFi 与 AI 配置。网页服务沿用热点访问范围，没有新增互联网服务器。

## 设备相册与视频的文件操作（1.8.0）

- 短按文件行仍打开照片或视频；长按文件行打开重命名输入框，支持拼音输入中文。
- 每行右侧“⋮”打开文件菜单，选择“删除文件”后再确认；取消或侧边返回不修改文件。重命名时首次侧边返回收起键盘，再次返回关闭输入框。
- 重命名保留照片 `.bin`、视频 `.rvf` 格式。视频存在同名 WAV 时一并重命名，例如 `trip.rvf` 和 `trip.wav` 会一起改为 `海边.rvf` 和 `海边.wav`。删除视频时也删除其已有的同名配套 WAV。
- 同名目标或同名配套音频已存在时拒绝覆盖。网页正在上传、照片仍在读取或视频未关闭时，文件操作会提示稍后重试。
- 文件操作在后台任务完成，结束后重新扫描并刷新当前列表。文件名不能包含路径、FAT 不支持的符号或空名称；过长名称需要缩短。
- 私有 `/.media-edit/` 保存操作记录、独立提交标记及临时文件。操作未提交时恢复原名，已提交的删除会完成清理；恢复在 SD 挂载后、上传和界面启动前执行。损坏或存在冲突的恢复信息会保留文件并阻止新上传，避免覆盖。

相关源码：`src/MediaActions.c`、`src/MediaFiles.cpp`；验证：`tests/media_actions_ui_host_test.py`、`tests/media_files_host_test.py`。主机文件测试覆盖配套 WAV、大小写改名、同名冲突、阶段失败、每次重命名边界的模拟中断及损坏记录保留；真实 LVGL 测试覆盖触摸、拼音、菜单、确认、取消和反复销毁输入法。
