# 中文与英文输入

适用于 AI 助手、照片/视频重命名、热点名称、本机音乐搜索和城市输入。热点密码保留英文、数字和符号输入。

1.26.0 起采用四排手机式 QWERTY：第一排十个字母，第二排九个字母居中，第三排大小写、七个字母和退格，底部集中符号、123、标点、宽空格、中英文切换和确认。语言按钮占独立槽位，不遮挡空格。需要收起键盘时从屏幕侧边返回。

- 键盘底行的 **CN / EN** 按钮切换语言。CN 是中文拼音，EN 直接输入英文；ABC / abc 仍切换大小写。
- 中文模式输入拼音，点击候选字即可上屏。输入 `nihao` 时，可先选“你”，再选“好”；尚未选择的拼音继续保留。当前采用拼音切分逐字选字，不提供整词联想词库。
- 候选栏 **< / >** 每次翻 6 个字；**更多** 展开为每页最多 24 个字，通过“上一页 / 下一页”查看其余候选，“收起”返回键盘。
- 切换语言或收起键盘，会保留输入框中的文字并结束本次拼音组合。没有匹配时隐藏候选，不保留上一组字。
- 超长英文会继续保留在输入框中；内部拼音缓冲始终限制长度。移动光标或改写输入框后，不会用旧候选删除其他文字。

中文候选沿用 SD 卡 `/ime/pinyin_full.txt`。1.26.0 城市名称需要同步更新 `/fonts/chinese_20.bin` 与 `/fonts/chinese_32.bin`，同时更新包内 `/ime/pinyin_full.txt` 以增加 8 个城市用字候选。没有 SD 词典时，部分页面只有少量备用候选。字库包含某个字不等于拼音备用词典也包含它，完整城市输入建议保留 SD 完整词典。

1.26.1 修复旧 OTA 镜像中空格键被隐藏的问题。底部的 `Space` 键在字母、数字与符号页均可见，每次输入一个 ASCII 空格；不会输入标签文字。已经安装 1.26.0 字体与词典的设备，本次只需更新 OTA。
