# v1.5 发布说明

发布日期：2026-10-08。新增设备信息和 HTTP/HTTPS 文字浏览器，包含实机验证通过的百度正文读取修复。继承 v1.4 的视频音频、串口 SD 素材上传、LRC 原样上传及 AI 服务器备份。

## 新增功能

- 设置中的设备信息：显示用户确认的 ESP32-S3 N16R8 模组、API 读取的芯片型号与版本、固件版本、CPU 核心数和频率，以及内部 RAM、PSRAM、Flash 已用／总量。Flash 已用仅统计当前固件大小，不代表全部分区占用。
- 文字浏览器：输入网址，读取 UTF-8 HTML、XHTML 或纯文字，支持滚动、正文分页、最多 8 个链接、后退、刷新及取消。支持 HTTP、HTTPS、IP 地址和显式端口。
- 固件版本标识更新为 `v1.5`，在设备信息页显示。

## 浏览器修复

- 预留 10 KiB 内部 RAM 静态任务栈，复用通知驱动的工作任务，避免 WiFi 连接后内部内存碎片导致任务无法启动。
- 仅把浏览器任务中的 TLS 内存分配移至 PSRAM，其他任务继续使用原 SDK 分配器；HTTPS 保留 CA 证书校验。
- 使用移动网页兼容的 User-Agent，避免百度对旧标识返回没有正文的脚本跳转页面。
- 用 512 字节 PSRAM 缓冲流式读取正文，替代 `HTTPClient::writeToStream` 的 4 KiB 内部缓冲，给硬件 AES 保留内部 DMA 内存；支持 Content-Length、连接关闭结尾和 chunked 解码。
- RGB 显示提交调用移出关中断临界区，提交后等待新的帧完成事件。原 10 MHz PCLK、20 行 bounce 缓冲、双帧缓冲、背光及 WiFi 配置保持不变；实际视觉稳定性仍待确认。

## 验证范围

- v1.5 固件编译通过：静态 RAM 199,428／327,680 字节，应用 Flash 1,888,786／3,342,336 字节。
- HTML 解析、HTTP 正文解码及二者集成的三组 C 回归检查通过；HTML 与 HTTP 解码分别通过 600 组异常输入检查，覆盖中文、分块边界、截断、断流及异常格式。
- 版本标识更新前、相同浏览器实现的诊断固件实机读取 `https://example.com/`、`https://www.baidu.com/`、`https://baidu.com/` 和 `http://www.baidu.com/` 均成功。百度三个入口各读取约 79 KB 内容，解析出 265 字节文字及 8 个链接，该轮未捕获 AES 内存分配失败。
- 自动测试代码已移除。v1.5 正常操作固件已通过 COM3 烧录及四处写入校验，随后 25 秒串口观察未捕获故障，LCD 约 35 FPS；这不代表完整浏览器操作或屏幕视觉效果已验收。
- `http://YOUR_SERVER_HOST:3000/` 在电脑只读 GET 检查中返回 HTTP 200 的“AI聊天”HTML；尚未实测 ESP32 打开该地址。其静态文字可以解析，聊天输入与发送依赖 JavaScript。
- 视频音频、串口 WAV 上传及 SD 读回校验沿用 v1.4 的验证记录，本次没有修改播放与上传逻辑，也没有重新完整验收这些场景。

## 当前限制

- 浏览器不运行 JavaScript、不还原 CSS、不显示网页图片或视频，也不能操作网页表单。依赖脚本的网站可能只有少量文字或没有可读正文。
- 不支持压缩正文及 GBK 等非 UTF-8 编码。正文最多 12 KiB，下载最多 256 KiB；超限保留已读取内容并标记截断。HTTPS 需要有效设备时间。
- WiFi 连接后的屏幕撕裂仍需实机视觉确认，不能宣称已修复。完整触摸翻页、链接跳转、取消和资源释放操作也需继续补充实机验收。
- 视频帧率没有新增优化；v1.4 实测 20 FPS 源视频呈现约 10 FPS，不能据此推断 v1.5 的所有播放场景。
- 服务器备份未重新部署，空机器重建和完整 AI/TTS 链路仍待验证。未修改或重启线上服务。

## 下载与使用

[公开源码](https://github.com/banli12345/ESP32SmartVoiceBox-public) 公开仓库提供源码快照，不附带预编译固件，包含应用固件、配套启动文件、SHA-256 校验值、版本清单和分段烧录说明。适用于本工程接线的 ESP32-S3、16 MB Flash、8 MB OPI PSRAM，Flash 为 DIO／80 MHz。

上位机没有修改，继续使用 [公开源码](https://github.com/banli12345/ESP32SmartVoiceBox-public) 的 `SDMediaUploader-v1.4-windows.zip`，兼容 v1.5 接收协议。本次没有重新发布上位机附件。

字体、图标及音视频素材另行准备，烧录固件不会自动部署 SD 资源。用法见[部署指南](GETTING_STARTED.md)、[文字浏览器](text-browser.md)与[串口素材上位机](SERIAL_MEDIA_UPLOADER.md)。旧 `v1.2`、`v1.3`、`v1.4` 标签保持原位置。
