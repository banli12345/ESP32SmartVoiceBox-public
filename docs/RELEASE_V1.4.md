# v1.4 发布说明

发布日期：2026-10-08。本版本发布已实机使用的串口素材上传和视频音频代码；固件源码以 `41d55c5` 为基础，发布整理不改变屏幕、Wi-Fi 或播放逻辑。

## 新增功能

- Windows 串口素材上位机：壁纸 PNG/JPG 转 480×480 BIN，照片转 480×450 BIN，MP3 转 PCM WAV，MP4 转 320×240 RVF 并提取同名音轨。
- ESP32 串口 SD 接收端：115200 握手、921600 上传、16 KiB 分块、CRC32 和 SD 读回校验，校验后整批替换文件。
- 视频音频：RVF 与同名 44100 Hz、双声道 PCM16 WAV 配对，按音频进度同步画面，支持循环和退出后恢复音乐。
- LRC 歌词原样上传，不转码、不修改文件内容；设备中文歌词使用 UTF-8 文件。
- 配套 AI 服务器源码和部署模板位于 `server/`，真实服务器密钥和私人配置不纳入 Git 或发布附件。

## 已完成的验证

- 固件编译、COM3 烧录及写入校验通过；SD_MMC 以 40 MHz、1-bit 挂载，根目录检查通过。
- 通过实际 `SerialUploader` 传输模块上传 `/videos/ikun20.wav`，设备端读回 CRC32 校验、整批提交和重启通过。
- 用户实机确认 `ikun20` 视频声音、音画同步、循环和退出视频后恢复音乐正常。
- 2026-10-08 主机转换/传输回归检查共 44 项通过；Windows 上位机图形初始化和内置 FFmpeg 自检通过。
- v1.3 对照测试结束后已烧回上位机上传版，固件文件 SHA-256 为 `267bd30f5de1c5f87ffcb18b768d78cd62f97da6b541337974f47d25ccbd6d17`。

## 已知问题与待验证项目

- 用户仍观察到轻微整屏明暗闪动；稳定 v1.3 对照也有相同表现。原因尚未定位，不能据此确认是硬件故障。本次不包含此前未奏效的屏幕缓冲、重同步或 Wi-Fi 低功率实验改动；使用原来的 10 MHz PCLK、20 行 bounce 缓冲及背光配置。
- LCD VSYNC 约 35 FPS；320×240、20 FPS 源视频实际呈现约 10 FPS，保留现有抗锯齿。
- 完整图形上位机的壁纸、照片、MP3/LRC、RVF/WAV 配对上传，以及实机取消/异常中断恢复、视频与闹铃/AI 语音切换仍需补充测试。已通过的 WAV 传输和播放验证不能覆盖这些场景。
- AI 服务器备份未重新部署；从空机器重建和完整 AI/TTS 链路尚未验证。

## 下载与使用

[公开源码](https://github.com/banli12345/ESP32SmartVoiceBox-public)公开仓库仅提供已清理的源码。

- `ESP32SmartVoiceBox-v1.4-firmware.zip`：包含应用固件、配套启动文件、校验值和分段烧录说明。板卡配置为 ESP32-S3、16 MB Flash、8 MB OPI PSRAM、Flash DIO/80 MHz。
- `SDMediaUploader-v1.4-windows.zip`：解压后保留整个目录，运行 `SDMediaUploader/SDMediaUploader.exe`，内含 Python 运行库和 FFmpeg，无需另装它们。
- 字体、图标、原始媒体和 SD 运行素材需另行准备，不包含在上述发布包内。烧录和素材部署是两步操作，见[部署指南](GETTING_STARTED.md)与[上位机文档](SERIAL_MEDIA_UPLOADER.md)。

旧 `v1.2`、`v1.3` 标签保持不变。v1.4 不清空设备配置或 SD 素材；更新后仍需按对应格式准备资源。
