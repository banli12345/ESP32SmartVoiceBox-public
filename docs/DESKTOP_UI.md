# 桌面、侧边返回与图标排序

当前Breeze OS 1.28.0有12个稳定ID应用，使用清新绿色配色。桌面左右切换及进入/退出应用采用约180ms层叠侧滑与窄边阴影，应用内部直接显示；天气和校时在后台执行。早期书本翻页效果已移除。详见[当前动效](FONTS_AND_MOTION.md)。

主页时钟按变化数位翻动；右上两行显示穿衣、紫外线、感冒和运动指数。日期卡的公历、农历共用中心线，中文星期位于公历右侧，节气和节日无内容时隐藏。天气卡区分室外天气温度与MPU芯片温度。

## 侧边返回

页面顶部原来的弯箭头返回键已替换为手势：从屏幕左侧或右侧边缘的中段
向内拖约一指宽，看到绿色返回提示后松手。只拉出一点再松手会取消。
顶部边缘仍用于下拉快捷面板；桌面横向翻页请从屏幕中间开始滑动。

- 设置里的 WiFi、亮度、音量等子页返回设置首页。
- 照片大图和视频播放页返回各自列表，沿用原有加载取消、播放退出和资源清理。
- AI、WiFi 密码和城市输入页先收起正在显示的键盘，再次内滑离开页面。
- 浏览器先收起键盘，再返回上一网页；没有可返回网页时退出浏览器。
- 确认弹窗先被关闭，不会直接跳走或确认重启。
- 应用页和 SD 信息页内滑返回桌面；天气详情先返回应用列表。

## 长按移动应用

进入“应用”页，按住图标约半秒，卡片高亮后拖到目标位置再松手。其他图标
会让出位置，松手完成排序。长按和拖动不会打开应用，也不会触发桌面翻页。
新的顺序保存在 NVS，重新打开应用页、从天气返回或设备重启后仍会恢复。
若保存失败，页面会提示重试，原有已保存顺序保留。

## 源码与验证

- `FlipClock.c/.h`：按数位更新的双阶段翻板动效；隐藏时即时更新，删除时取消动画。
- `flip_digits_72.c`：从工程自带 Montserrat 字形生成的数字字库，脚本为
  `scripts/generate_flip_digits.py`，无需额外 SD 字库或运行时缩放缓存。
- `AppLauncher.c/.h`：应用卡片、长按拖动、插入排序及 NVS 单次提交；读取时
  校验版本、数量与排列，损坏配置恢复默认顺序，不清空其他配置。
- `EdgeBack.c/.h`：左右边缘手势、返回提示、取消阈值、延后执行原页面返回处理，
  以及屏幕删除时清理绑定；`main.cpp` 统一协调下拉、返回、图标拖动和桌面翻页。

运行 `python tests/desktop_ui_host_test.py` 可使用实际 LVGL、工程图标和 SD
中文字库渲染桌面与应用页，并驱动生产触摸回调。覆盖拖动及持久化、NVS 失败、
非法排列、普通翻页、双侧返回及取消、弹窗、页面删除、滑条与下拉隔离，
以及时钟进位、隐藏更新、多实例和动画中删除。预览和 GIF 输出到忽略目录
`.tools/desktop-ui-20261114/host/`。快捷面板回归入口为
`python tests/quick_panel_host_test.py`。这些主机检查不能替代设备触摸实测。
