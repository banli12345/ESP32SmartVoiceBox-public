# v1.6 发布说明

发布日期：2026-10-09。将 v1.5 之后已经完成的设备与屏幕重启、渐变主题、中文名称显示和音频修复整合为正式版本，并更新壁纸页的温度图标。

## 界面与操作

- 壁纸页温度图标改为深色轮廓、白色管体、红色液柱和六条长短交替刻度，透明背景；尺寸从 64×64 缩小到 40×40，温度数字在下方居中，继续显示 MPU 传感器温度。
- 应用列表、SD 状态、设置、WiFi、设备信息、素材列表与浏览器采用淡草绿到米白渐变，搭配浅色卡片与深绿色文字。音乐、2048 和壁纸时钟页沿用原样式。
- 天气页面使用蓝天渐变、白云、太阳装饰和三日预报卡片，天气数据与天气图标继续按实际信息更新。
- 热点名称、照片及视频列表使用 20px 中文字库；显示中文需要 SD 中已有对应字库。
- 设置增加“重启设备”：确认后执行软复位，返回主界面并保留已保存的设置。开机约 1 秒后发起已保存 WiFi 的连接，重启过程会断开当前连接。
- 设置增加“重启屏幕”：在 VSYNC 帧边界暂停 RGB 输出，重新启动已有控制器和 DMA，恢复背光亮度并重绘，保留 ESP32 运行状态与 WiFi 连接。等待帧边界最多 500 ms，失败时可以重试。

## 音频修复

- 视频 WAV 采用只读 VFS 文件描述符直接读取，替代缓冲 stdio 路径，修复实际播放时文件头异常导致的无声；SD 上的同名 `.rvf` 与 `.wav` 配对方式不变。
- 短读保留已经取得的 PCM 数据，并在下一未读位置最多重试三次；持续失败时停止音轨并记录文件与偏移。退出视频可以取消重试。
- 静音输出计数增加饱和减法，避免部分写入和 DMA 回调同时发生时计数回绕。
- AI 在收到并验证可播放的 WAV 后再占用音频输出，HTTP 或文件头失败不会提前停掉音乐或视频；输出释放与视频任务取消由音频任务统一处理。

## 验证范围

- v1.6 固件编译通过：静态 RAM 192,036／327,680 字节，应用 Flash 1,894,502／3,342,336 字节。温度图标缓冲由 12,288 字节降为 4,800 字节，节省 7,488 字节。
- 温度图标直接使用本工程 LVGL 8.3.1 的画布渲染器生成预览，检查了浅色与深色背景上的轮廓、液柱和透明区域。
- 最终 v1.6 固件已通过 COM16 烧录及四处写入校验；随后 60 秒启动观察未捕获崩溃或看门狗故障，LCD 为 35～36 FPS。这一轮没有自动打开视频，音频实机结论来自下述相同实现的验证记录。
- 屏幕恢复、AI／音乐／视频输出交接、短读恢复和静音计数的主机检查通过；WAV 解析及音画调度检查通过。真实 `ikun20.wav` 的三次打开、六次 PCM 全量循环与交错 RVF 读取均逐字节比对通过。
- 图标修改前、相同音频实现的实机验证记录到三次音轨启动（含重新打开和中文名视频）及一次完整循环，无音轨错误或缓冲耗尽；用户确认“声音持续正常”。移除自动播放代码后，正常操作固件也成功启动中文名视频音轨。
- 屏幕重启开发阶段已记录三次成功、每次约 60 ms，用户确认恢复效果正常。该结果证明恢复操作可用，不代表根治了 WiFi 相关画面异常。
- 浏览器和串口素材上传继承 v1.5／v1.4 的验证记录，本次未修改其传输或转换协议。完整硬件场景覆盖仍需要继续补充。

## 下载与使用

[公开源码](https://github.com/banli12345/ESP32SmartVoiceBox-public) 公开仓库提供源码快照，不附带预编译固件，包含应用固件、启动文件、SHA-256 校验、版本清单与分段烧录说明。适用于本工程接线的 ESP32-S3、16 MB Flash、8 MB OPI PSRAM，Flash DIO／80 MHz。

Windows 上位机继续使用 [公开源码](https://github.com/banli12345/ESP32SmartVoiceBox-public) 的 `SDMediaUploader-v1.4-windows.zip`。字体、壁纸及音视频素材另行准备；温度图标由固件绘制，无需更新 SD 图标文件。部署步骤见 [GETTING_STARTED.md](GETTING_STARTED.md) 和 [串口素材上位机说明](SERIAL_MEDIA_UPLOADER.md)。

## 当前限制

- 屏幕重启用于恢复显示，WiFi 连接后的持续撕裂仍可能发生。
- 文字浏览器不执行 JavaScript、不还原 CSS、不能操作网页表单或播放网页媒体；仅支持其现有 UTF-8 正文读取范围。
- 视频实际呈现帧率受 SD 读取、缩放与音轨读取影响，20 FPS 源文件不保证达到 20 FPS；本次未增加视频画面优化。
- 服务器源码与配置沿用已有备份，未重新部署线上服务，空机器重建和完整 AI/TTS 链路不在本次验证范围内。

旧版本 `v1.2`、`v1.3`、`v1.4`、`v1.5` 标签保持原位置。
