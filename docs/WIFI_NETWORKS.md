# WiFi 多网络连接（1.21.0）

进入“设置 → WiFi”，开启后会在后台搜索网络。已有单个 WiFi 的保存记录自动迁移，升级无需擦除 NVS 或重新填写原密码。

| 操作/状态 | 当前行为 |
| --- | --- |
| 短按“已保存”网络 | 使用已保存密码连接，已连接其他网络时切换到所选网络 |
| 短按当前“已连接”网络 | 保持当前连接 |
| 短按未保存的加密网络 | 输入密码并确认 |
| 短按未保存的开放网络 | 无需密码，直接尝试连接 |
| 长按网络 | 打开空白密码框，可重填新密码；不回显旧密码 |
| 确认密码 | 回到列表显示进度，取得所选网络 IP 后才保存 |
| 断线或重新开启 WiFi | 扫描后自动寻找可见的已保存网络 |
| 已正常连接 | 保持当前网络，不因扫描发现其他已保存网络而自动切换 |

最多保存 8 个成功网络，同一 SSID 更新已有记录。优先使用最近成功的可见网络；失败后尝试其他候选，并限制重复尝试频率。密码错误或超时不会覆盖之前有效的保存密码，长按可重新填写。

扫描、驱动调用和配置保存交给后台，界面提交请求后可继续滚动或侧边返回。刷新按钮显示扫描状态，完成后自动更新。关闭 WiFi 会停止自动连接；热点仍按自己的开关工作。

## 保存与实现

凭据保存在设备 NVS，和心知天气、DeepSeek API 配置无关，不写到 SD 或公开源码。版本化记录有固定上限；保存失败保留原记录，不擦除其他设备设置。

`src/setwifi.cpp` 负责扫描和连接服务，`src/WifiProfiles.*` 管理保存记录，`src/ui/custom/custom.c` 显示列表并提交请求。热点名称、密码和 NAPT 分别维护。

## OTA 后实机检查

1. 从热点网页上传新应用 BIN，在“设置 → 系统更新”安装。
2. 分别成功连接两个 2.4 GHz 网络，再短按另一个已保存网络，确认无需重输密码。
3. 重启或关闭/打开 WiFi，检查能否自动连接可见的已保存网络。
4. 路由器改密码后，长按重填；确认错误密码不会作为成功记录保存。
5. 开启热点后切换上游，检查手机可访问设备网页，上游连接后恢复共享网络。

主机测试不代替真实路由器认证、DHCP、断线恢复和热点共存验证，正式设备结果另行记录。
