# 在设备浏览器使用本机音乐页

从 IDF **1.15.0** 起，ESP32 屏幕上的浏览器可打开本机音乐页，直接搜索、播放并保存歌曲。

## 打开页面

1. 已使用当前 IDF 双槽分区的设备，先通过热点网页上传对应应用 OTA BIN，再到“设置 → 系统更新”检查并安装。
2. 在设备应用页打开“浏览器”，保留默认地址 `http://172.31.42.1/`，点击“打开”；也可输入 `http://127.0.0.1/` 或 `http://localhost/` 后点击“打开”。
3. 已开启热点时，输入热点设置显示的本机网址同样进入音乐页；设备当前连接 WiFi 获得的本机 IP 也可识别。

`127.0.0.1` 在这里表示设备自己。设备上的本机页面适配入口不要求开启热点；联网搜索和下载需要设备连接可上网的 WiFi。手机打开热点网页仍需开启热点。

## 搜歌、存歌和播放

- 在歌名输入框输入歌名或歌手，使用底部键盘和拼音候选选字，点击搜索。
- 从结果中选一首播放，只写可复用的临时 MP3 缓存，不加入本地歌单。
- 当前歌曲旁的“下载”才会将这首歌转换、保存为 WAV/LRC，并加入本地歌单。暂停时也可下载，不会重新播放；重新搜索其他歌曲后，下载仍对应当前播放的歌曲。
- 查看页面的实际准备、下载、保存结果。保存可能持续数分钟，以“WAV 已保存”和歌词结果为准；不要在保存结束前点停止或切换歌曲。
- 保存名沿用 `歌名 - 歌手.wav`、同名 `.lrc`，文件位于 `/music/`。歌词取决于平台是否提供，不会凭空生成歌词。
- 保存成功后可播放已保存的 WAV，也可进入本地歌单，再次离线播放。退出本机音乐页不会主动停止正在播放或保存的歌曲。
- 暂停、继续和停止使用设备现有的同一套播放器；停止也会取消尚未完成的准备与保存。
- 键盘打开时侧边内拉先收起键盘，再次返回浏览器。进入本地歌单后可返回音乐页继续操作。

播放和保存均需要可用的 SD 卡。临时 MP3 缓存使用 `/.online/song0.mp3`、`song1.mp3` 两个可复用槽，不会按每首歌无限累积；只有点击“下载”才永久写入 `/music/`。搜索歌曲本身不需要写入 SD 卡。手机热点网页与设备本机音乐页的规则一致。

## 页面适配范围

这是对工程**已知本机音乐页**的 LVGL 交互适配：复用手机网页的 `OnlineMusic`、`MusicSave` 和 `Sound` 功能，在设备上绘制可触摸的控件。

它不执行任意 HTML / JavaScript，也不等同于移植 Chrome。其他网址继续使用原有文字浏览器；抖音等复杂视频网页不在这次范围内。手机网页的照片、视频、固件上传仍由手机浏览器完成。

本机识别限定为 HTTP 默认 80 端口的根页面，支持 `localhost`、`127.0.0.1`、当前热点地址和当前 WiFi 地址；其他主机、路径和端口不会被误当作本机音乐页。HTTPS 没有在本机服务器上启用，请使用上面的 HTTP 地址。

音乐来源、平台曲目限制、保存文件格式和已有实机验证范围见 [在线音乐说明](ONLINE_MUSIC.md)。
